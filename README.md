# Velora — Restaurant Website Demo

A responsive, one-page restaurant website built with HTML, CSS, and JavaScript.

## Preview locally
Open `index.html` in a browser. An internet connection is needed for Google Fonts and the Unsplash photos.

## Publish it free
1. Create a GitHub account and a new repository.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. In repository Settings → Pages, choose deploy from the `main` branch and `/ (root)`.
4. GitHub Pages will provide a public URL after deployment.

You can also drag the project folder into Netlify Drop at https://app.netlify.com/drop for a quick static deployment.

## Before using it for a real business
This is a portfolio demo concept, not a real restaurant. Replace the sample address, email, opening hours, prices, and menu with accurate information. The reservation button currently opens an email draft and is not connected to a booking system. Food photography is loaded from Unsplash URLs.
